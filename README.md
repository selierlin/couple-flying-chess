# 情侣飞行棋2 · Couple Flying Chess

两人同屏的互动飞行棋网页游戏。掷骰子、走格子、每格触发一个互动任务，先到终点者获胜。

**在线玩**：[chess2.linliang.top](https://chess2.linliang.top/)

---

## 特点

- **免安装免注册** — 手机浏览器打开即玩，iOS / Android 通用
- **多种模式** — 恋爱版、普通版、高阶版、四人版、默契考验等 14 种
- **双人同屏** — 一部手机两人轮流操作，也可以两人各开一台异地连麦
- **自定义任务** — 自己填任务内容，`#` 分隔，开局自动生成任务池
- **强度分档** — 按关键词自动判定轻 / 中 / 重 / 极限四档，越接近终点越靠后

## 怎么玩

1. 手机横放或平放在两人中间
2. 轮流点击骰子，棋子自动按点数移动
3. 落到任务格，按卡片提示完成
4. 先到终点者获胜
